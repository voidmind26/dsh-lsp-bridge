# 通用 LSP 插件设计

## 目标

向 DSH 的 LLM 提供只读语义查询工具，而不是让模型通过 shell 手工拼接 LSP 协议。支持用户配置任意遵循 stdio LSP 的语言服务器，并处理多仓、多语言、多根目录项目。

## 工作区与路由

以当前 DSH 会话工作目录为访问边界。语言通过文件扩展名匹配配置；通过最近的项目标记文件（如 go.mod、tsconfig.json）或显式 roots 确定根目录。多个服务匹配同一文件时允许指定 server 消除歧义。按工作区、服务器及项目根目录区分实例，避免将多个独立 Go module 错当一个项目。仅在用户配置 workspaceFolders 时组合多根工作区，是否能跨根解析符号仍取决于语言服务器和项目依赖关系。

uos 示例包含多个独立 Go module 与 Vue 工程；默认按 module 隔离，配置示例演示显式根目录。插件不修改 uos、go.mod、go.work 或前端依赖。

## 协议与工具

- JSON-RPC 2.0 + Content-Length 分帧，通过 stdio 通信，不使用 shell。
- 懒启动、initialize/initialized、配置传递、按请求读取磁盘并同步文档。
- 查询操作：状态、悬浮、定义、类型定义、实现、引用、文档符号、工作区符号、诊断。
- 输入行列号从 1 开始，列按 UTF-16 计数；原始 LSP 输出位置从 0 开始。
- 不提供任意方法透传、重命名、代码动作执行或应用 WorkspaceEdit。
- 请求超时、取消、异常退出时清理待处理请求；插件卸载时关闭进程。
- DSH 适配器使用会话对象身份 + 工作目录作为常驻引擎边界；引擎内部按语言服务器、项目根目录和多根目录配置复用实例。不同会话不共享进程。
- 配置 `idleTimeoutMs`（默认 300000）及 `maxSessions`（默认 4），空闲引擎自动回收；请求活动期间不做空闲回收。容量满时仅可回收空闲引擎，全部繁忙则拒绝额外会话。
- 每次调用检查权限；监听真实 `session/event` 的 `sandbox/mode` 事件和 `session/disposed` 事件。权限收紧取消请求并关闭对应进程，插件卸载关闭全部实例。每秒检查有效策略，为没有独立事件的默认策略变化兜底，不承诺 OS 级即时撤销。
- 回收中的引擎不可被新请求复用，关闭完成前仍计入容量。会话重载产生新对象时不会继承旧对象的进程。

## 安全边界

配置中的语言服务器是用户信任的本地程序，具备执行代码和读取项目依赖的能力。“只读查询”不代表语言服务器进程本身被操作系统沙箱限制。首版若不能通过 DSH 接口可靠施加会话沙箱，则仅在当前会话允许 danger-full-access 时启动，不绕过受限会话权限。

模型不能指定服务器命令或环境变量；这些只能来自插件配置。模型指定的文件与根目录必须经过 realpath 校验，不允许通过路径穿越或符号链接逃出当前工作区。

## 验证

使用模拟 LSP 服务覆盖协议、参数、文档同步、多根路由、错误与清理；使用本地 gopls 在隔离临时工程中进行真实语义查询。安装到运行中 DSH 和 GUI 验证作为单独步骤，不将单元测试通过等同于已在 GUI 生效。
